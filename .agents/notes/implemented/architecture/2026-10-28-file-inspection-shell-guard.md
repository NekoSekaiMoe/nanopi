# Agent Note: shell 读文件命令的判定层

Status: implemented

## Problem

`cat -n f`、`sed -n '1,80p' f`、`grep -rn foo` 是模型的肌肉记忆。issue #344 的结论是只在
提示层引导（#346 落地），issue #354 说明提示不够：提示词每精简一轮，那条偏好规则就更靠近
末尾，而 slash 命令、子 agent 的起步消息里根本没有系统提示。

代价是具体的：`cat -n` 的编号要模型自己维护、没有截断提示、没有 gitignore、shell 引号要
自己躲；`read` 有 offset 续读、有「超长单行」的诊断，`edit` 还靠它记录的快照判断文件是否
过期。用得差不是风格问题，是丢功能。

## Decision

`packages/extra/src/shell-guard.ts` 判**一行命令是不是纯读文件**，命中就在 `tool_call`
里直接 `block`（不是弹授权框），拒绝原因点名替代它的工具调用。

判定只是窄窄的一条缝，中间是它拦的、两边是它不碰的：

- 拦：`cat [flags] <files>`、`head`/`tail [flags] <files>`、
  `sed -n '<打印范围>' <files>`、递归 `grep`/`rg`（`rg` 默认递归）。
- 不拦（形态）：整行只要还有别的用途就放行——管道（`cat f | wc -l` 是在喂另一个程序）、
  重定向、子 shell、`sed -i`、`grep -q/-l/-c/-o`、`cat -`、heredoc、多行命令、`$()`、
  它看不懂的任何东西（`checked: false`，和 git guard 同一个取值方向：漏一次提示，而不是错拦）。
- 不拦（目标）：`cat *.ts`、`cat /dev/null`、不存在的路径。`read` 答不了这些，拦了只是让
  模型绕路。只有真实存在的普通文件才算。
- 不拦（缺替代）：替代工具没被声明就不拦。没有 `read`，`cat` 没有替代品；没有 `grep`，
  `rg` 也不该被拦。子 agent、`--tools` 裁剪过的会话靠这条自动让路，不需要额外开关。

默认开启，`/shellguard off` 关闭（`ExtraSettings.shellGuard`，全局或项目 settings.json
均可写）。默认开是因为误伤面被上面几条压住了，而「默认关」等于 issue 没解决。

## 为什么是拒绝而不是问人

`git guard` 拦的是**危险**，需要人判断「这次是不是真要 stash」，所以走授权门。
`cat f` 不是危险，是**策略**：没有需要人来判断的东西。把它放进授权通道，会让「读个文件」
和「rm -rf」共用同一个提问框，问多了人就不看框了。拒绝的代价是模型多一次工具调用，
好处是那一行拒绝原因就是它下一轮唯一读得到的东西。

## Alternatives considered

- **继续加强提示（#346 已做）**：改一条规则只是把概率挪一点，而且每轮精简都要重新守住它；
  模型记住的不是「规则」，是「上次这么干被拒了」。
- **默认关闭、只留 settings 开关（#344 的原提议）**：默认关等于没解决，而这条守卫的误伤面
  已经被窄判定压住，默认开 + `/shellguard off` 收尾更符合「工具优先」的定位。
- **弹权限框而不是拒绝**：见上一节，它会把策略和危险混进同一个通道。
- **拦 `ls -la`、`grep foo f` 这些「会话里确实还能用」的形态**：它们的输出正是人要看的
  形态，替代工具给不了，拦了只是让模型学会包装命令。
- **在 `bash` 工具里判**：与 git guard 相同——判定只留一处，且 `extra` 本来就在 `tool_call` 上；
  `--yolo` 下也照样拦，因为它拦的是策略，不是危险。

## Consequences

收益：模型想读文件时，第一次 `cat` 会被顶回 `read`，并且只有这一条路；提示词不用再为
这条偏好付预算，精简时也不怕它被删掉。

代价与已知漏口：`bash -c 'cat f'`、`sudo -u x cat f`、`$(cat f)` 没进判定器——它们比直接写
`cat f` 少见得多，要覆盖就得再维护一层 shell 语法模型，眼下不值得。真的漏多了再加。

另一个代价只在非危险意义上成立：有人用 `cat` 看二进制或长尾输出时会被顶回 `read`，
`read` 对非普通文件会明确拒绝并指向 bash，所以这条路是通的，只是多一跳。
